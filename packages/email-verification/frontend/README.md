# @caffeineai/email-verification
Email verification package for [Caffeine AI](https://caffeine.ai?utm_source=caffeine-skill-npm&utm_medium=referral).

React hook for the verification landing page of a Caffeine app: reads the token from the link in the verification email and confirms the address through the app's own backend canister when the recipient clicks.

## Install

```bash
pnpm add @caffeineai/email-verification
```
