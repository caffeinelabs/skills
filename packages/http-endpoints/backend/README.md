# caffeineai-http-endpoints
HTTP endpoints package for [Caffeine AI](https://caffeine.ai?utm_source=caffeine-skill-mops&utm_medium=referral).

Inbound HTTP via the IC HTTP Gateway (`http_request` / `http_request_update`). Not for outbound HTTPS outcalls.

## Install

```
mops add caffeineai-http-endpoints
```

See [github.com/caffeinelabs/skills](https://github.com/caffeinelabs/skills) for integration guides.
