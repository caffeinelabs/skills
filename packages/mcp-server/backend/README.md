# caffeineai-mcp-server
MCP server package for [Caffeine AI](https://caffeine.ai?utm_source=caffeine-skill-mops&utm_medium=referral).

Serve an MCP server from a Motoko backend canister, so users connect the app to Claude and other MCP clients. Users sign in with Internet Identity on the app's own site, through OAuth 2.1 with PKCE.

## Install

```
mops add caffeineai-mcp-server
```

See [github.com/caffeinelabs/skills](https://github.com/caffeinelabs/skills) for integration guides.
